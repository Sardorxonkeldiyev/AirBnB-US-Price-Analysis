# AirBnB Data Analysis Project - US Housing Market 🏠📊

## Project Overview
This project presents a comprehensive data visualization and analysis of the US AirBnB market, focusing on rental prices, seasonality, and property characteristics. The analysis was performed at a granular level, specifically targeting **Zip Code** distributions to identify high-value areas and market trends.

The goal of this project was to transform raw AirBnB data into an interactive and actionable dashboard that helps stakeholders understand pricing dynamics across the United States.

## Key Features & Dashboards
The Tableau workbook consists of several detailed visualizations, including:

* **Geospatial Price Mapping:** An interactive map of the US that visualizes average rental prices by Zip Code, allowing for quick identification of the most expensive and affordable neighborhoods.
* **Seasonality Trends:** A time-series analysis showing how prices fluctuate throughout the year (2016), helping to identify peak travel seasons and price volatility.
* **Price per Bedroom Analysis:** A comparative bar chart that illustrates how the number of bedrooms impacts the average listing price, providing insights for property investors.
* **Listings Distribution:** A statistical overview of the total count of listings, categorized by location and property type.
* **Revenue & Volume Metrics:** Key Performance Indicators (KPIs) showing total revenue potential and listing volume across different states.
* **Advanced Filtering:** Interactive filters for City, State, and Zip Code that allow users to drill down into specific micro-markets.

## Tools & Technologies Used
* **Tableau Desktop/Public** - For advanced data visualization and dashboard orchestration.
* **Microsoft Excel** - For initial data cleaning, formatting, and preparation.
* **Data Analysis Techniques** - Aggregations, calculated fields, and spatial joining.
